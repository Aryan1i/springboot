# ☕ Java Backend Development | Spring & Spring Boot

Welcome to my **Java Backend Development** repository!

This repository documents my journey of learning Java backend technologies, starting from JDBC and progressing towards Hibernate, JPA, Spring, and Spring Boot.

It contains topic-wise practice programs, hands-on implementations, and projects that demonstrate my understanding of backend development concepts.

I continuously update this repository as I learn new technologies and build practical applications.

## 📚 Learning Progress

### 1. JDBC (Java Database Connectivity)

Hands-on learning and implementation of JDBC concepts.

- JDBC Fundamentals
- DriverManager and Connection
- Statement and PreparedStatement
- ResultSet
- Properties File Configuration
- SQL Injection Prevention
- Batch Processing
- Transaction Management
- BLOB and CLOB Handling
- Date Handling
- CallableStatement
- Stored Procedures
- Connection Pooling using HikariCP

### 2. JDBC CRUD Project

A practical Employee Management application built using JDBC and MySQL.

**Features:**
- Create Employee
- Retrieve Employee Details
- Update Employee Information
- Delete Employee Records

**Architecture and Implementation:**
- DAO Layer
- Service Layer
- Model Layer
- Database Utility
- MySQL Integration
- HikariCP Connection Pooling

### 3. Hibernate

Learning Hibernate ORM to simplify database interactions using Java objects.

Topics include:
- Hibernate Fundamentals
- ORM Concepts
- Entity Mapping
- Configuration and SessionFactory
- CRUD Operations
- Entity Relationships
- One-to-One Mapping
- One-to-Many Mapping
- Many-to-One Mapping
- Hibernate Caching

### 4. JPA (Java Persistence API)

Exploring JPA concepts and persistence management in Java applications.

Topics include:
- JPA Fundamentals
- Entity Management
- Object Relational Mapping
- Persistence Configuration
- Entity Relationships
- Persistence Operations

### 5. Spring & Spring Boot

Continuously expanding my knowledge of the Spring ecosystem and modern Java backend development.
